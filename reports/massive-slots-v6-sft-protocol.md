# 四槽抽取 v6 次级实验：同 1,600 组的 Qwen QLoRA SFT 协议

状态：**仅开发集；测试集不纳入本实验，也不需要为它解封。**

主实验 [v6](massive-slots-v6-design.md) 在 600 条独立测试上给出新混合系统严格实体 F1 **62.59%**，绝对门槛全部通过，但预设的主要相对门槛（新混合减旧 v5 混合的配对区间下界 >0）实测 **−3.58 个百分点**，因此总体判定失败。这不是本实验要修正的问题。

## 研究问题与边界

本实验只回答一个问题：**在同一批 1,600 个训练组上，Qwen 4-bit QLoRA SFT 的最终权重，在冻结开发集上与当轮字符 BIO 相比处于什么水平。** 它是设计文档中的次级后训练实验，作用是给主实验补一个同样本、不同配方的参照点。

边界必须写清楚：

- **它不进入主系统选型。** 主候选、门控规则和阈值 `−0.08` 都不因本实验改变。
- **它不参与 v6 主验收。** 主实验的通过与否已在测试报告里判定完毕，本实验不能追溯修改那个判定。
- **它不做测试集评测。** 设计文档要求任何 SFT 测试评估都必须在 v6 测试开启前另行固定方案和模型指纹；该窗口已过。因此在当前协议下 SFT 的实验范围就到开发集为止，封存测试集不对本实验解封。
- **它不能与主实验混合报告。** SFT 分数属于另一个模型，不能与 BIO 或混合系统的分数合并成一个"v6 成绩"。

## 固定配方

与设计文档一致，不做任何搜索或检查点挑选：

| 项目 | 固定值 |
| --- | --- |
| 基座 | `models/Qwen2.5-0.5B-Instruct`（冻结，与主实验同一份权重） |
| 训练数据 | `data/massive-zh/slots-v6/train.jsonl`，1,600 组，SHA-256 `ea1cd537dcfd924b24eec7997b692a42ae9df757c52f89c904358665ec06a3d3` |
| 量化 | 4-bit NF4 双量化，计算精度 float32，LoRA 只训练注意力投影 |
| 学习率 | `3e-4` |
| 批大小／梯度累计 | 1／4 |
| 序列长度 | 256 |
| 训练步数 | 400 optimizer steps（约一次训练遍历） |
| 随机种子 | `20261003` |
| 评测权重 | 只评最终保存权重，不挑检查点 |

入口为 `scripts/train_massive_slots_v6_sft.py`。它在训练前强制执行设计要求的模板与遮罩预检：用真实 tokenizer 和 TRL 的实际预处理路径逐条检查 1,600 条，要求提示词被遮罩、补全参与损失、训练与推理的对话前缀一致，**任何一条超过 `max_length` 就停止并记录，不做静默截断**。预检结果写入运行清单，因此本次训练不存在被截断的样本（实测最长 160 token，最短补全 6 token）。

## 评测协议

入口为 `scripts/evaluate_massive_slots_v6_sft.py`，**结构上无法读取测试集**：它只构造 `dev.jsonl` 路径，并在参数不是 `dev` 时直接拒绝。评测沿用主实验冻结的同一套规则：

- 同一 300 条开发集（SHA-256 `6ee1812c5ac9a12e44047cd57e5973be606b9dcdf546d1d30ccf96f4ff1a157c`）。
- 同一贪心生成：batch 8、输入上限 256 token、输出上限 64 token，不做输出修复。
- 同一严格实体指标：按每句 `(类型, 原文逐字值)` 多重集匹配，同时报告总体 F1、阳性子集 F1、无槽失败率和三项合法率。
- 同一配对 bootstrap：1,000 次、种子 `20261003`、按强归一化原句组聚类。

为得到同样本比较，评测脚本在**同一批 300 行**上重新载入并重新评分五个冻结基线（旧／新 BIO、v4 DPO、旧 v5 混合、新混合）的逐题预测，核对行序、原句组哈希和切分哈希后才计算配对差值。因此报告里的差值是本批句子的配对 bootstrap，而不是两份报告之间的算术相减。

报告写入 `reports/massive-slots-v6-sft-dev.json`，逐题预测留在 Git 忽略的 `_tmp/`。入口拒绝覆盖已有结果。

## 预期解释

无论结果如何，都只能作如下表述：在冻结开发集上，同一批 1,600 训练组用 SFT 配方与用字符 BIO 配方的差异。不能写成"v6 SFT 优于混合系统"（未比）、"DPO 有因果贡献"（本实验不含 DPO）、"可上线"（仍是研究结果，缺真实请求与拒绝校准）。
