# v6 次级 QLoRA SFT：固定开发集结果

**范围：开发集研究结论，不是 v6 主实验的独立测试成绩，也不用于改变已冻结的主系统。** 依照[事前协议](massive-slots-v6-sft-protocol.md)，在同一批 1,600 个训练原句组上训练 Qwen2.5-0.5B-Instruct 的 4-bit QLoRA SFT，固定 400 optimizer steps，只评最终权重。训练前 1,600 条样本全部通过模板、损失遮罩和长度预检。最终权重 SHA-256 为 `a976347121e29aa55d8de765c4703944bedcc8da5e466a7941ca2741dcc8023a`。

300 条冻结开发集来自 MASSIVE zh-CN，按强归一化原句组与训练集隔离；文件 SHA-256 为 `6ee1812c5ac9a12e44047cd57e5973be606b9dcdf546d1d30ccf96f4ff1a157c`。所有系统在同一批原句上按 `(类型, 原文逐字值)` 严格实体匹配。生成采用贪心解码、batch 8、输入上限 256 token、输出上限 64 token，不修复输出。完整机器可读结果见 [JSON 报告](massive-slots-v6-sft-dev.json)，逐题预测留在本机 Git 忽略目录。

| 系统 | 严格实体 F1 | 阳性句 F1 | 逐句全对 | 无槽失败 | 原文复制合法率 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 新 BIO，同 1,600 训练组 | 65.74% | 69.61% | 84.33% | 11/208（5.29%） | 100% |
| v6 冻结混合系统 | 66.10% | 73.24% | 81.00% | 22/208（10.58%） | 100% |
| v6 QLoRA SFT，400 步 | **69.49%** | **78.85%** | 81.33% | **29/208（13.94%）** | **99.00%** |

SFT 相对同组新 BIO 的 F1 点估计高 **3.75 个百分点**，按原句组配对 bootstrap 1,000 次的 95% 区间为 **−5.41 至 +13.44 个百分点**；相对冻结混合系统高 **3.39 个百分点**，区间 **−4.11 至 +10.78**。两个区间都跨 0，**没有确认 SFT 的总体优势**。SFT 的 JSON 与结构合法率各为 100%，但有 3 条值未逐字复制；无槽失败率高于新 BIO，且逐句全对率低于新 BIO。这是更高阳性召回与更多无槽错误之间的实际权衡，不能只报告总体 F1。

本次没有搜索检查点、阈值或解码参数，也没有为 SFT 打开 600 条独立测试集。因此不能把 69.49% 与主实验测试集的 62.59% 直接比较，不能改写 v6 主实验“绝对门槛通过、相对增量未确认”的结论，更不能把该适配器作为自动执行服务。若未来要确认 SFT 收益，需要另行预注册全新测试切分、部署资源与拒判门槛。
